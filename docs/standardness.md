# Standardness checklist

Consensus validity and relay/mining standardness are separate. Each complete
script assembled from these fragments must be checked for:

- serialized script, transaction, and witness size limits;
- opcode and execution-budget limits for its script version;
- combined main-stack and altstack item limits;
- minimal pushes and minimally encoded Script integers;
- cleanstack and a truthy final result;
- P2SH/P2WSH/tapscript-specific policy limits;
- one-time-key and witness-hint requirements imposed by the primitive.

The metric snapshots report generated bytes, not a blanket claim that every
parameter choice is standard. Large lookup tables and BN254 hinted arithmetic
are primarily research constructions and commonly exceed default relay policy.
